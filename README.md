# Органические соединения ЛР5

Потапов Данил, ИУ5-54Б. Тема №20 — определение формулы органического соединения по продуктам сгорания.

Отдельный репозиторий фронтенда: https://github.com/DanilkaPotapov/organic-compounds-frontend
Бэкенд ЛР4: https://github.com/DanilkaPotapov/organic-combustition-backend/tree/lab4-organic-compounds
Ветка этой работы: lab5-organic-compounds. Основная ветка также содержит текущий код, поэтому корень репозитория не пустой.

## Запуск

Node.js не ниже 20.19, npm. Из папки проекта:

```bash
npm ci
npm run dev
```

Открыть http://localhost:5175/organic_compounds/grid. Docker и бэкенд для ЛР5 не нужны. `npm run build` проверяет TypeScript и собирает dist; `npm run preview` показывает сборку на порту 4175.

## Четыре страницы итогового приложения

### 1 Плитка соединений

Маршрут `/organic_compounds/grid`. Реализована в ЛР5 для гостя. Показывает шесть локальных mock-карточек: название, формулу, изображение, количества C/H и число лайков. Поле «Количество атомов C» принимает целое число от 1. Кнопка «Найти» применяет точный фильтр к коллекции; «Сбросить фильтр» возвращает все записи. При C=2 остаются этан, этен и этанол. Нажатие карточки открывает её ленту по id. При отсутствии результата отображается пустое состояние. Шестерёнка открывает сведения о режиме просмотра и кнопку «Закрыть».

### 2 Лента соединений

Маршруты `/organic_compounds/feed` и `/organic_compounds/feed/:id`. Реализована в ЛР5 для гостя. Показывает одно вертикальное видео, название, формулу, C/H, краткое описание и количество лайков. «Ещё» раскрывает описание, «Свернуть» скрывает. «Следующее соединение» переключает по коллекции с возвратом к первой карточке. Кнопка проигрывателя ставит видео на паузу и продолжает воспроизведение. Гость видит число лайков, но не изменяет его. Ошибочный id показывает ссылку «Открыть плитку».

### 3 Добавление соединения

Пункт меню «Добавление» присутствует, но недоступен гостю в ЛР5. Реализация страницы относится к следующему этапу с бэкендом. Первый шаг: name, image, video и кнопка «Далее» — POST /api/organic_compounds. Второй шаг: shortDescription, carbonCount, hydrogenCount и кнопка «Опубликовать» — PUT /api/organic_compounds/:id/publish. Существующий черновик получается GET /api/organic_compounds/draft. Фото над видео; служебные поля клиент не задаёт. Это описание целевого интерфейса, а не заявление о реализации его в ЛР5.

### 4 Вход и регистрация

Пункт «Вход» присутствует и недоступен в ЛР5. Реализация относится к следующему этапу. Целевая страница содержит email, password и «Войти» (POST /api/users/auth); для регистрации дополнительно name и «Зарегистрироваться» (POST /api/users/register). Пароль маскируется. После входа отображается «Выход», POST /api/users/logout. Сессия хранится в Redis, браузер хранит HttpOnly cookie. В ЛР5 запросы аутентификации не отправляются.

## Данные и компоненты

`src/data/organicCompounds.ts` — шесть mock-объектов; запросов API нет. `App` хранит применённый фильтр в useState и передаёт его через props. `CarbonFilter` хранит введённое значение и вызывает onApply. `GridPage` передаёт compound компоненту CompoundCard. `FeedPage` получает id через useParams и переключает страницу через useNavigate.

`CompoundImage` подставляет public/media/default-organic-compound.svg при пустом URL и ошибке загрузки. `CompoundVideo` аналогично использует default-organic-compound.webm; повторная ошибка показывает локальную картинку. Метанол имеет пустые URL и служит примером fallback. Все медиа находятся в проекте.

## Хуки

useState: фильтр App, ввод CarbonFilter, описание FeedPage, проигрыватель CompoundVideo, шестерёнка Header, fallback CompoundImage. useEffect: заголовок окна в App, сброс раскрытия в FeedPage, запуск и остановка видео в CompoundVideo. useRef: доступ к video. useLocation, useNavigate, useParams — маршрутизация. Redux и Context не используются.

## Порядок девяти скриншотов

6. Код CarbonFilter и передача props из App/GridPage.
7. useState/useEffect в App и FeedPage.
8. useRef/useEffect и cleanup в CompoundVideo; useState Header.
9. Этот README в новом репозитории: видны код, ветка и четыре описания страниц.
